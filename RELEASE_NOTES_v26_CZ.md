# SPITE – Neoficiální český překlad 1.0 🇨🇿

**Verze překladu:** 1.0  
**Verze hry:** SPITE 1.7.0 (podle původního souboru `app.asar`)  
**Systém:** Windows  
**Cena:** Zdarma

Fanouškovský český překlad dialogů, příběhových scén, voleb, popisů a herního rozhraní. Překlad byl opakovaně testován, přesto se mohou objevit další chyby.

**Stažení:** V sekci **Assets** stáhněte soubor `SPITE_Cestina_1.0.zip`. Automaticky přidané archivy *Source code* nejsou instalátorem překladu.

Instalační návod je uvnitř ZIP archivu. Stačí jej rozbalit (například WinRARem) a spustit `INSTALOVAT_CESTINU.bat`. Python není nutný.

Patch vyžaduje vlastní kompatibilní originální kopii hry a neobsahuje žádné úpravy herních mechanik. Po aktualizaci hry může být potřeba nový patch.

**Upozornění:** Toto je neoficiální, bezplatná fanouškovská lokalizace, kterou vývojář hry neschválil. Chyby a nepřeložené texty můžete hlásit v komentářích ke Steam návodu.
